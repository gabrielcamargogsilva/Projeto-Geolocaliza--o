# 📍 Projeto Geolocalização

> Aplicação web desenvolvida para consumo e visualização de dados de geolocalização e mapas em tempo real via API.

🔗 **Acesse o repositório:** [https://github.com/gabrielcamargogsilva/Projeto-Geolocaliza--o](https://github.com/gabrielcamargogsilva/Projeto-Geolocaliza--o)

---

## 📌 Sobre o Projeto

O **Projeto Geolocalização** foi construído com o objetivo de praticar o consumo de APIs RESTful focadas em mapas e localização geográfica. A aplicação permite realizar requisições assíncronas para capturar coordenadas, endereços ou dados de posição do usuário/dispositivo e exibi-los de forma dinâmica e interativa na interface.

---

## 🚀 Funcionalidades

- 🌍 **Consulta de Localização:** Captura e processamento de coordenadas geográficas via API.
- 🗺️ **Visualização Interativa:** Exibição dinâmica de mapas e pontos de interesse no front-end.
- ⚡ **Requisições Assíncronas:** Consumo dinâmico de dados com JavaScript (`fetch` / `async/await`).
- 📱 **Interface Responsiva:** Layout adaptado para diferentes tamanhos de tela.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da aplicação.
* **CSS3:** Estilização visual, layout flexível e responsividade.
* **JavaScript (ES6+):** Manipulação da DOM, tratamento de eventos e consumo da API de localização.
* **API de Geolocalização:** Integração com serviço/API externa de mapas e coordenadas.
